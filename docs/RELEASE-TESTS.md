# 0.2.0-rc1 驗證記錄

日期：2026-11-07。來源以 Git 標籤 `v0.2.0-rc1` 為準；Windows 本機 Chrome、Playwright 無頭瀏覽器。下列結果係程式功能證據，唔係真人遊玩或商業品質保證。

通過嘅測試組：

1. `browser-smoke`：360／390px、旅行、留守、懸賞、舊檔及重新開始。
2. `behavior-regressions`：揹人、集合／追兵、守衛、宰割、撤退。
3. `economy-crafting`：有限商店、資金、配方、舊檔及製作循環。
4. `village-caravan-mining`：貧村、遊商跨區、鐵礦及搜身。
5. `forge-exploration`：鍛冶場、有限秘藏、追兵、圖樣及裝備。
6. `forge-fog`：視野、繪圖與點擊、跨區探索記錄。
7. `discovered-landmarks`：只記錄已發現地點，唔洩漏敵情／物資。
8. `starvation-rescue`：自救／瀕死、餵食、暫停及存讀。
9. `shared-food`：實際行近分糧、指令優先、距離、存讀及跨區隔離。
10. `save-portability`：真正下載及選檔匯入、無效檔案／儲存失敗隔離、備份交換、損壞檔保護。
11. `border-campaign`：三路線及死亡結局、真實點箱取物／返村交付、選擇鎖定、自然跟隨到路牌、跨區揹人／友軍讀檔、名將、招募及一次性獎勵。
12. `offline-release`：對解壓後嘅 `file://` 遊戲斷網開啟，實際存檔、下載／選檔匯入，零遠端請求及執行錯誤。

另做：預設人物數值、關閉主動追敵、以正常行走／旅行／搜查指令完成首個尋糧來回；冇改血量、傳送角色或殺清敵人。此單次檢查唔代表整段故事嘅難度／時長已經驗證。

審查修正：村中守衛同被揹返村嘅友軍身份分開恢復；護送隊長會等同行者到路牌，傷者要揹，亦可明確叫佢原地等候。委託物不可出售或因普通掉落物逾時而消失。

仍待：真人新手測試、完整三路線節奏與長時間運行、實機觸控／Edge／其他瀏覽器、商品素材權利及商店資料。未驗證項目唔會寫成已支援或已完成。
