# 發行包素材盤點 · 0.2.0-rc1

此表記錄目前包內實際使用嘅素材類型，唔代表已完成權利歸屬或法律審查。

| 項目 | 來源／位置 | 發行狀態 |
| --- | --- | --- |
| 人物、倒地姿勢、地形、建築、特效 | `js/render.js`、`js/world.js` 等專案 Canvas 繪圖程式 | 下載包包含程式；擁有人仍需確認既有開發成果權利 |
| 介面、圖示 | `index.html` 嘅 CSS 及 inline SVG | 隨程式附帶，冇獨立圖示資產檔；權利盤點同上 |
| 字體 | 使用玩家裝置嘅系統字體 | 冇打包字體檔，已移除 Google Fonts 網上請求 |
| 故事、對話、原創人物 | `js/campaign.js` | 今次開發新增；青葉村、阿澄、軍令、委託及會面係虛構 |
| 真實人物及背景參考 | 武田信玄、上杉謙信、川中島背景 | 只參照史實背景；冇複製博物館圖像、他作立繪、文章或名將對白 |
| 音樂、音效、照片、精靈圖 | 目前冇 | 未納入此候選版；唔應喺商店頁聲稱有配樂或語音 |
| 第三方執行時套件 | 目前冇 | Playwright 只作開發測試，唔隨下載包分發 |
