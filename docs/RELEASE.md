# 下載版候選版本

產品暫名：**機關浪人：川霧之間**。首個目標平台係 Windows Chrome／Edge，保留直向畫面；其他平台、手機觸控及效能未經完整實機驗證。

候選版本唔代表已適合收費。正式售賣前，要完成以下檢查並記錄結果：

- 新玩家由教學玩到結局，能理解指令、飢餓／倒地、救援及故事選擇；記錄耗時、卡關、重玩意願同錯誤。
- 確認每條故事路線都有可達結局，玩家選擇有後果；困難、失敗同全隊陣亡都有清楚提示。
- 驗證舊存檔、更新後讀檔、匯出／匯入、無痕／儲存被拒絕、損壞檔案同離線啟動；更新前提醒玩家備份。
- 解壓後以 `file://` 啟動，斷網測試；網頁版及下載版分開檢查，唔假設兩者自動共用進度。
- 實測 Windows Chrome／Edge 嘅長時間運行、螢幕尺寸同操作；未驗證平台唔寫入支援承諾。
- 核對所有程式、美術、字體、音效、音樂及文字嘅來源與商用權利；見 `ASSET-PROVENANCE.md`（如有）。授權不明就移除或更換，唔以本清單當成法律確認。
- 準備真實遊戲截圖、準確內容與支援平台描述、版本／更新說明、支援與問題回報方式；由擁有人確認售價、發行者資料及商店條款。

## 產生離線 ZIP

需要 Python 3.9+，只用標準函式庫；可由任何工作目錄執行：

```powershell
python D:\Git\wasteland\scripts\package-release.py --version 0.2.0-rc1
```

可用 `--output <資料夾>` 指定輸出位置，預設係 repo 嘅 `dist/`。工具會檢查頁面資源、拒絕遠端執行依賴或遺失檔案，將遊戲、玩家說明及現有素材來源／授權文件打包，輸出 ZIP 同 SHA-256。固定輸入會產生相同 ZIP；唔會自動建立商店頁或上架。

發布前重新產生最終包，檢查 SHA-256，解壓後再跑實際玩家流程。上載嘅 ZIP 必須係完成上述檢查嗰一份。
