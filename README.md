# 機關浪人 · 架空戰國原型

手機優先嘅 2.5D 等角視角小隊操作原型，用嚟測試：

- 青葉村 → 荒寺山道 → 廢棄鍛冶場：點路牌揀相連目的地，已選隊友自動集合出發；帶埋揹住嘅傷者。交戰亦可離開，近距離追兵會跟過區，可引去村中足輕附近。點路牌或落新指令可取消集合；可切換任何區域嘅留守隊。
- 荒寺遺留箱可搜查一次；帶舊寺銅印返村出售、補給、醫傷再出發。
- 新開箱嘅荒寺圖錄藏箱只有 2 份玉鋼，唔夠整齊所有進階裝備；既有存檔箱內容保持原狀。鍛冶場外圍有少量補給，內圈兩箱共 4 份玉鋼、2 個精密機關零件及機關圖樣，附近浪人較強。可引開敵人搜箱撤退，毋須清場；三箱只可搜一次。圖樣帶返村工匠解鎖機關護胴，減傷較玉鋼胴丸高，唔喺商店補貨。
- 舊版兩區存檔會加入鍛冶場，保留舊區屍體、空箱、隊伍、商店、圖錄解鎖及遊商行程；新區及新圖樣解鎖亦會存檔。
- 商人／宿屋／每個遊商各有有限貨量同銀兩；買貨、工錢、租床會入商人錢箱，賣貨按商人資金部分收購。每 600 秒遊戲時間補足基本貨量同資金，暫停及離線唔計時；切區、讀檔唔會重置。
- 青葉村貧村配額：村店飯糰 2、藥包／修具／舊脇差／布衣／木鐵機關肢各 1，基本資金 180 文；宿屋飯糰 2、藥包 1、資金 50 文。精製義肢及較好武裝交由遊商供應；舊店庫存一次套用新配額，玩家背包及製作解鎖保留。
- 遊商與護衛實際經路牌跨區：青葉村停留 60 秒 → 荒寺山道停留 60 秒 → 外地 120 秒 → 返村。途中行路／等護衛另計，遇襲會耽擱；其他區域嘅商隊亦會繼續行程。商人身分、庫存、護衛及外地行程會存檔；返村唔會洗貨。
- 礦石顯示與可採礦清單一致：村西銅礦、山道北面鐵礦；路牌有查看礦脈功能。倒地角色「搜身／取裝備」顯示空身提示，重疊時先揀目標；目標途中醒返會取消搜身。
- 青葉村商人有「工匠」頁：犬肉製熟肉、銅鐵礦製修具、犬皮製皮甲。只用交易隊友背包材料，交工錢即時製成。
- 荒寺工匠藏箱有鍛冶圖錄及有限玉鋼；交圖錄永久解鎖全隊配方。玉鋼打刀、玉鋼胴丸及匠製機關肢優於商店最高級成品，基礎商店唔補呢啲製作品。舊存檔會加入新藏箱，搜清後唔會刷新；落武者只執散落物及屍體，唔搜固定藏箱。
- 新生成嘅野武士頭目會帶 1 塊玉鋼，之後可透過更難嘅討伐繼續取得製作材料。
- 留守隊可切換控制，其他區域暫停模擬；敵人、屍體、掉落物同搜查狀態會保留。

- 長按拖曳框選／框選模式
- 雙擊頭像鏡頭跟隨
- 戰術暫停（暫停時指令排隊）同慢鏡
- 行為規則 AI（重傷撤退、安全休養至 60%、近身自衛；手動指令優先，另有救人醫人、見敵就打）
- 成長循環：五部位傷勢（頭、身、左手、右手、腳）、用嚟練技能（耐打、攻擊、閃避、急救）、野犬竇練功場、角色卡
- 三層傷勢：殘廢（可醫）、斷肢（永久，可裝木鐵／精製機關肢，用機關修具修理）、流血同陣亡（硬派模式，可關）
- 經濟：執敵人裝備去賣、採銅鐵礦、生擒懸賞犯交俾足輕、喺商人度買義肢同維修工具
- 揹人期間可回復或流血，但放低先可起身；背包同負重（練力量）、武器同盔甲
- 倒地動物宰割取皮／肉會死亡，首次取材須按兩次確認（包括全部拎走）
- 倒地按血量回復先醒、流血致死、野犬咬同野武士補刀
- 地上物品堆（5 分鐘消失）、交俾隊友
- 青葉村關係值：交懸賞加分、攻擊足輕變敵對、友好有折扣
- 自動存檔（瀏覽器本地）、藥包同宿屋租床、飢餓同飯糰
- 落武者（執地上嘢）、遊商隊（流動商店）、酒場招募（最多 8 人）、移除陣亡隊友

`index.html` + `js/`，遊戲冇執行時依賴，直接用瀏覽器開就玩得。

新版讀取 `wl_save_sengoku_v1`，首次可匯入 `wl_save_v1`，保留角色、背包、傷勢、技能同金錢，將隊伍安置喺青葉村。原版存檔保留作回退；確認「重新開始」會刪除新舊兩份存檔，並阻止離頁自動存檔寫返舊進度。

開本地 HTTP server 後可用 `node tests/browser-smoke.cjs` 測試。測試需可 resolve 嘅 Playwright 同本機 Chrome；可用 `WASTELAND_TEST_URL`、`WASTELAND_CHROME` 指定地址同瀏覽器。涵蓋重新開始、舊檔匯入、分區存讀、留守／揹人、懸賞、搜查返村出售及手機直向尺寸。

`node tests/behavior-regressions.cjs` 驗證揹人回復／放低、操作掣可點擊、自動集合與取消、追兵跨區／守衛反擊、動物宰割確認及重傷撤退。

`node tests/economy-crafting.cjs` 驗證有限商店、資金流向、部分收購、每日補給、舊檔相容，以及探索／採礦／解鎖製作／裝備／存讀檔循環。

`node tests/village-caravan-mining.cjs` 驗證貧村配額、舊店調整、遊商跨區離村與存讀檔返程、真正點擊鐵礦採礦，以及重疊／空身搜身操作。

`node tests/forge-exploration.cjs` 驗證兩區舊檔升級、路牌多目的地、實際點擊外圍箱／步行搜查、有限秘藏、揹傷者連追兵兩段撤退，以及帶圖樣返村解鎖／製作／存讀檔。
